# ESRDC Blog Website

A clean Next.js starter for building the ESRDC blog from scratch.

## Development

Install dependencies:

```bash
npm.cmd install
```

Run the dev server:

```bash
npm.cmd run dev
```

Open `http://localhost:3000` in your browser.

## Structure

- `app/layout.tsx` defines the root layout and metadata.
- `app/page.tsx` is the homepage.
- `app/globals.css` contains the global styles and Tailwind import.
